Explore a small version of the ideas behind my work. These are self-contained browser demos — no account, no API request and no data sent to a server.

LAB / 01COGNIFY MODEL

Where should control live?

Select a layer to see its responsibility in a governed tool-call path.

COMPONENT / 01SELECTED

Agent identity

A governed action should be attributable to a specific agent identity and bounded by the permissions assigned to it. Identity is context for policy evaluation, not a substitute for policy.

DESIGN PRINCIPLEAttribution before authorisation.

Conceptual flow. Cognify governs actions routed through its MCP server; it does not intercept arbitrary agent traffic outside that boundary.

LAB / 02SECURITY UTILITY

JWT structure inspector

Decode the header and payload of a JSON Web Token locally. This tool does not verify the signature or establish trust.

WAITING FOR INPUT

Header and payload appear here after inspection.

!

Decode ≠ verify. The signature is not checked. Do not paste production tokens, credentials or sensitive personal data into a public webpage.
